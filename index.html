Структури даних: Списки та Матриці

Комплексний огляд одновимірних масивів (потяг) та двовимірних таблиць (багатоповерховий будинок) у мові Python.

Що таке список (List)?

Впорядкований контейнер для зберігання послідовності об'єктів під одним іменем.

  • • Синтаксис: Квадратні дужки [1, 2, 3]
  • • Типи даних: Може містити числа, рядки, дроби разом
  • • Змінюваність: Елементи можна модифікувати після створення

Індексація та Анатомія

Індексація завжди починається з **0**. Від'ємні індекси відраховують з кінця (-1).

# animals = ['Кіт', 'Собака', 'Миша', 'Хом'як']

print(animals[0]) # Виведе: 'Кіт'

print(animals[-1]) # Виведе: 'Хом'як'

print(len(animals)) # Довжина: 4

Методи vs Функції

.append(x) — додати в кінець
.remove(x) — вилучити за значенням
sum(a) — сума елементів
sorted(a) — сортування

Двовимірні Матриці (Таблиці)

У Python таблиця реалізується як список списків (List of Lists).

table = [[1, 7, 17], [8, 18, 19]]

# Доступ: table[рядок][стовпчик]

print(table[1][2]) # Результат: 19
