## 📁 Структура репозиторію:
- `index.html` — основна інтерактивна сторінка проекту.
- `README.md` — опис проекту.

## 🌐 Інструкція з публікації на GitHub Pages:
1. Завантажте вміст архіву у новий GitHub-репозиторій.
2. Перейдіть у **Settings -> Pages**.
3. У полі **Branch** виберіть `main` і натисніть **Save**.
4. Сторінка стане доступною за декілька хвилин!
